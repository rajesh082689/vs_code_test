# CLAUDE.md

## Project
Small Python practice project.

- `add.py` — adds two integers; prompts for input when run directly.

## Running code
- Use `py` to run scripts (e.g. `py add.py`). The `python` command is not on PATH on this machine.
- Platform is Windows; the default shell is PowerShell.

## Code style
- Keep code simple and readable.
- Use type hints on function signatures.
- Put script entry logic under `if __name__ == "__main__":`.
